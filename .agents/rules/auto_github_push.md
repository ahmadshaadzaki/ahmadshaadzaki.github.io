# Rule: Auto Git Stage, Commit & Push to GitHub

- Whenever any file is created, modified, or deleted in this portfolio workspace upon user request, ALWAYS run:
  ```bash
  git add .
  git commit -m "<descriptive message of user changes>"
  git push origin main
  ```
- Do not stop at local edits — always deploy the changes live to GitHub (`https://github.com/ahmadshaadzaki/ahmadshaadzaki.github.io`).
